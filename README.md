# Web View Fabric
Fahri Qeizal Sabil - 41155050240020

## Deskripsi
Tugas ini merupakan aplikasi Android berbasis React Native yang menerapkan arsitektur rendering terbaru Fabric (New Architecture) untuk mengoptimalkan integrasi dan performa komponen react-native-webview. Dengan mengaktifkan New Architecture, aplikasi ini mampu menampilkan dan mengeksekusi halaman web eksternal secara native di dalam aplikasi dengan antarmuka yang lebih responsif, performa rendering yang lebih cepat, serta komunikasi antarmuka yang efisien tanpa bergantung pada mekanisme bridge tradisional.
